# 🧠 Data Structures Implementation in C++

A collection of fundamental data structures implemented from scratch in C++. This repository serves as both a learning resource and a reference for core CS concepts.

## 📋 Implementations

| Data Structure       | Key Features                          | File                     |
|----------------------|---------------------------------------|--------------------------|
| **Dynamic Arrays**   | 1D/2D memory management               | `1D array`, `2D array`   |
| **AVL Tree**         | Self-balancing BST with rotations     | `AVL Tree.cpp`           |
| **Linked Lists**     | Circular/Doubly with deletion         | `Circular*`, `Doubly*`   |
| **Graph Algorithms** | Dijkstra's shortest path              | `Dijistra.cpp`           |

## 🛠️ Tech Stack
- **Language**: C++ (STL used minimally for clarity)
- **Concepts**: Pointers, Memory Management, OOP
- **Tools**: GCC/Clang, Make (optional)
